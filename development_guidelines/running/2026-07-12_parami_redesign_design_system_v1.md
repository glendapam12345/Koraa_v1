# Para mí redesign — Design System v1

**Fecha:** 2026-07-12  
**Estado:** running  
**Relacionado:** [2026-07-11_koraa_design_system_v1.md](./2026-07-11_koraa_design_system_v1.md)

## Objetivo

Aplicar **1 hero / 1 CTA / 1 sección de apoyo** a Para mí: menos dashboard, más calma.

## Cambios

- Header: `Para mí` / `Tu ritmo, sin prisa`
- **Hero:** patrón centrado (`ParaMiPatternInsightCard`) o un solo insight
- **Apoyo:** card de ánimo con más aire (mist); energía + emociones detrás de progressive disclosure
- **Consejos:** grid visual 2 columnas (ilustración + título + pastilla)
- Preview freemium: una card alta con lock + CTA
- Más `sectionGap` entre bloques (una sola respiración)
- Kit de emergencia compact al final

## Verificar en dispositivo

- [ ] Sin datos: copy vacío suave, sin lista de insights
- [ ] Con patrón: un hero de patrón, no lista de insights debajo
- [ ] Premium: mood visible; energía/emociones solo al expandir
- [ ] Free: preview de una gráfica + CTA
- [ ] Sin “gentle tip” / tip destacado; categorías en lista legible
- [ ] Kit de emergencia no compite con el hero
