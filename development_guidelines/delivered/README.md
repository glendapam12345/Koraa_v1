# Delivered Directory

This directory archives completed work, finished features, and delivered improvements.

## Purpose

Maintain a record of completed work for reference, documentation, and learning.

## What to Include

- **Completed features**: Features that have been delivered
- **Finished refactors**: Refactoring work that's been completed
- **Resolved bugs**: Bugs that have been fixed (with solution documented)
- **Delivered improvements**: Performance, UX, or other improvements completed

## When to Move Here

Move files from `running/` to here when:

- Work is complete and merged/deployed
- All acceptance criteria are met
- Code review is approved
- Testing is complete

## Value

- **Reference**: See how previous features were implemented
- **Learning**: Understand solutions to past problems
- **Documentation**: Track what's been built
- **Onboarding**: Help new developers understand what's been done

## Example Files

- `feature-onboarding-flow.md` - Completed onboarding flow implementation
- `bugfix-auth-state-persistence.md` - Fixed authentication state persistence issue
- `refactor-theme-system.md` - Centralized theme system implementation
- `performance-query-optimization.md` - Database query optimization delivered

## File Naming

Keep the same name as in `running/` when moving files here.
